# Tree and Status

These terms describe how the proposed tree skills organize information for a reader.

## Language

**Familiar Hierarchy**:
A structure the reader already knows or can readily recognize from the product or the team’s everyday work organization.

**User Navigation**:
The product’s organization as encountered through navigation and screens by the person using it.

**Internal Work Hierarchy**:
The team’s existing organization of project work, such as the project and task structure in its work tracker.

**Suggested Grouping**:
A proposed new category presented separately by name, outside the tree’s default familiar hierarchy.

**Displayed Level**:
A depth in the visible tree beneath the implied project. The project itself is outside the displayed levels.

**Collapsed Branch**:
A named branch whose children are hidden in the current view and can be shown on request.

**Done**:
Completion relative to the conversation’s current phase, which may end at dev availability, review readiness, or production delivery.

**Needs Info**:
A work state or status judgment awaiting information the user can provide or help locate.

**Likely Stale**:
A freshness judgment that the available information may no longer reflect the item’s current state. It is separate from the item’s work status.
