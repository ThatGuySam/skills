## Why use it

**Get an event listing ready for review or make a scoped change to the existing Luma event.**

- **Use it when** you host a Luma event and need to edit the listing, review registration, change the date, or prepare a guest message.
- **You get** copy you can paste, a list of decisions still open, and a receipt for any authorized change the agent can verify.
- **Limit** Host actions require organizer access and explicit scope, including any automatic notifications.

Invoke it as `$luma-event-ops` in Codex, `/luma-event-ops` in Claude Code, or `/sams:luma-event-ops` with the collection bundle.
