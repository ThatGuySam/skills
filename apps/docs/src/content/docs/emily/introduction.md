## Why use it

**Get a clear next step for a manners question, with the 1922 source cited.**

- **Use it when:** you face an invitation, houseguest, introduction, condolence note, wedding, or workplace or digital manners question, or want to know what Emily Post wrote.
- **You get:** a recommendation, cited passages labeled direct or inferred, how the advice changes today, and wording you can use.
- **Limit:** it is not Emily Post or the Emily Post Institute, nor legal or safety advice. Its search missed a held-out accuracy target, so check citations.

Invoke it as `$emily` in Codex, `/emily` in Claude Code, or `/sams:emily` with the collection bundle. Add `-g` to the install command to install it globally.

## More prompts

```text wrap
Use $emily in Historical mode. What did Emily Post write about [topic], and what in it no longer applies?
```

```text wrap
Use $emily in Voice mode to draft a short note declining [invitation].
```

Voice mode returns a labeled pastiche. It never presents generated words as Emily Post's own.
