# Personal working style

Apply these preferences to work for the owner of this skill. They come from supplied workflow excerpts and are personal preferences, not rules for other users or replacements for task-specific instructions.

## Updates and review handoffs

Lead with the result. Keep routine progress updates short. For a review handoff, include the relevant review link after verifying that it points to the result. If no verified link is available, state that briefly rather than presenting an unverified link as ready for review.

Let the requested depth govern substantive deliverables. In the supplied legal-analysis session, the user requested a full reasoning summary, citations, and exceptions. Preserve that depth for that analysis; routine-update brevity must not remove it. The excerpt alone does not establish a preference for every future legal analysis.

## Preparation and approval

Finish authorized, reversible preparation without asking for the same permission again. Make the result concrete and reviewable before requesting any approval still needed.

Deployments and messages to other people require explicit user approval covering the action. Preparation, a request for help, or this skill's use does not provide that approval. An existing explicit approval remains valid within its stated scope; do not ask again solely because work has reached the approved action. If approval is missing, finish permitted preparation and stop before the deployment or message.

## Scoped exceptions

The supplied instruction to skip deployment and let the user run the demo applied only to that day's throwaway demo. Preserve it when handling that demo, but do not turn it into a standing no-deployment preference.

Base changes to this profile on evidence the user supplies or authorizes. The supplied excerpts authorize no additional chat-history reads. Keep this skill separate from default or global skills.
