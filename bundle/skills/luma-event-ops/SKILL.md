# Luma Event Operations

1. **Identify the event.** Resolve the exact event link or ID and, for host work, confirm the managing calendar and organizer access. Use the existing listing when the same event changes. Read the relevant current fields before drafting or acting. For a new event, identify its intended calendar and confirmed facts.
2. **Establish what the organizer authorized.** In-scope reads and local drafts can proceed without additional approval. Every external write needs explicit user scope for that action, even a remote draft. This covers creating and editing listings, changing visibility or access, approving guests, changing check-ins, inviting, submitting to partner calendars, scheduling or sending a blast, and publishing. Match the scope to the event, fields or action, audience where applicable, and notification side effects. If a save may send emails or calendar updates to guests or hosts and the user did not explicitly authorize those notifications, prepare the change and ask about the specific effect before saving.
3. **Read the relevant procedure.**
   - [Listing and admission](references/listing-and-admission.md) when preparing or reviewing a listing, setting host roles or visibility, configuring tickets and questions, or coordinating partner registration.
   - [Communications and feedback](references/comms-and-feedback.md) when rescheduling, inviting, sending or scheduling notices, reconciling check-ins, collecting feedback, or sharing follow-up resources.
   - [Access and verification](references/access-and-verification.md) when you need host-only fields, reach an access or send blocker, or verify and record an external action.
4. **Apply only the scoped changes.** If a consequential detail is missing, continue with read-only checks and paste-ready local drafts. Keep unresolved fields and decisions explicit. Leave raw guest information and private access links in organizer-controlled tools.
5. **Read back and report.** Reload or query the destination independently after writing and compare the saved fields with the authorized changes. Check the exact audience view or send record where relevant. Record a dated receipt for each external action or attempted action, including what was observed and anything still pending. When delivering a local draft, state the listing state you checked and any unknowns.
