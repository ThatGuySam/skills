This practice capture points to memory pressure as the likely cause of the tab-switching freezes. These are synthetic measurements, not readings from your Mac.

CPU has plenty of room: about 73% is idle. Safari and its web content report roughly 23 GB of memory on a 32 GB machine. Over just 10 seconds, swap use rises from 9 GB to almost 10 GB, with active swapping and memory compression. That suggests the system is moving data between RAM and disk as tabs need it.

Disk activity also rises to about 144–156 MB/s, consistent with that swapping, although this capture cannot attribute all disk traffic to it.

The most useful next step would be to save work and close unused Safari tabs or windows, then check whether switching tabs becomes smooth. If it does, browser memory use is the strongest lead.
