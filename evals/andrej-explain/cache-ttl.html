An illustrative cache model

When does a cache item stop being fresh?

An item is created at t = 0 seconds. Its time to live, or TTL, sets how long it can stay fresh. In this model it is fresh only while elapsed < TTL.

Start with 2 seconds elapsed and a 5-second TTL. The item is fresh because 2 < 5. Move elapsed time to 5 seconds to reach the exact boundary.

The boundary is excluded

At equality, elapsed < TTL is false. With a TTL of 5 seconds, the item stops being fresh at exactly 5 seconds, including that instant.

With TTL = 0, the item is never fresh in this model. Even at creation, 0 < 0 is false.

Model limits and source. This page implements the rule specified in the request. It is an illustrative model, not a prediction of any real cache. It models freshness only; it does not model deletion, fetching, or cache-specific behavior. Both controls use seconds from 0 to 10, in steps of 0.1.
